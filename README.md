
# Práctica 1: Mi primera contribución en GitHub

**Objetivo:** que el alumno se familiarice con repositorios, archivos, commits e historial, y documente lo que hizo en cada paso.


## Instrucciones para el alumno

**Paso 1. Acepta la invitación.** Revisa tu correo o entra a GitHub para aceptar la invitación al repositorio.

**Paso 2. Explora el repositorio.** Identifica el README, la carpeta `participantes/` y la pestaña **Commits**. Anota cuántos commits hay hasta ahora.

**Paso 3. Crea tu archivo.**
- Entra a la carpeta `participantes/`.
- Haz clic en **Add file → Create new file**.
- Nómbralo `apellido-nombre.md`, por ejemplo `perez-juan.md`.
- Pega esta plantilla y complétala:

```markdown
# Bitácora de [Tu nombre completo]

- **Usuario de GitHub:** @tuusuario
- **Carrera / grupo:**
- **Fecha:**

## Acciones realizadas

| # | Acción | ¿Qué aprendí o noté? |
|---|--------|----------------------|
| 1 | Acepté la invitación al repositorio | |
| 2 | Exploré el repositorio | |
| 3 | Creé este archivo | |

## Reflexión
¿Qué es un commit con mis propias palabras?
```

**Paso 4. Haz tu primer commit.**
- Haz clic en **Commit changes**.
- En el mensaje escribe algo descriptivo: `Agrego bitácora de Juan Pérez`.
- Deja seleccionado **Commit directly to the main branch** y confirma.

**Paso 5. Modifica tu archivo.**
- Abre tu archivo y haz clic en el ícono del lápiz.
- Agrega tres filas más a la tabla de acciones (por ejemplo: "Hice mi primer commit", "Edité mi archivo", "Revisé el historial").
- Haz otro commit con un mensaje distinto, por ejemplo `Actualizo mi bitácora con acciones 4 a 6`.

**Paso 6. Revisa el historial.**
- Entra a la pestaña **Commits** del repositorio y encuentra tus dos commits.
- Haz clic en uno y observa qué líneas aparecen en verde (agregadas) y rojo (eliminadas).
- Agrega a tu bitácora lo que observaste.

**Paso 7. Edita el archivo de un compañero.**
- Abre el archivo de otro compañero.
- Agrega al final una sección `## Comentario de [tu nombre]` con una observación positiva.
- Haz commit con el mensaje `Agrego comentario en bitácora de [compañero]`.

---

## Entregable y evaluación

El alumno entrega el enlace a su archivo de bitácora. Puedes evaluar con esta lista:

| Criterio | Puntos |
|----------|--------|
| Archivo creado en `participantes/` con el nombre correcto | 2 |
| Mínimo 2 commits propios con mensajes descriptivos | 3 |
| Bitácora con al menos 6 acciones documentadas | 3 |
| Comentario en el archivo de un compañero | 1 |
| Reflexión sobre qué es un commit | 1 |
| **Total** | **10** |
